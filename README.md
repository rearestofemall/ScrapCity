# Scrap City

Scrap City is a chaotic urban adventure set in a city built from junk, metal, and whatever people can find.

Explore the streets, overcome challenging obstacles, discover hidden areas, and survive the chaos.

## 🎮 Features

- Explore a unique scrap-built city
- Challenging gameplay
- Hidden areas and things to discover
- Gritty visual style
- Fast and simple gameplay
- Built with web technologies

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 🚀 Running the Game

Clone the repository:

```bash
git clone https://github.com/rearestofemall/ScrapCity
```

Open the project folder and launch `index.html` in your browser.

For the best experience, you can also run it through a local web server.
